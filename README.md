# Employee Management System

## About the Project

The Employee Management System is a simple web-based application used to manage employee information.

## Features

- Create new employee records
- Search employees
- Display all employees
- Edit employee details
- Delete employee records
- Employee count
- Data stored using browser Local Storage
- Responsive design

## Employee Details

The system stores:

- Employee ID
- Employee Name
- Email
- Phone
- Department
- Designation
- Salary

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
- GitHub Pages
